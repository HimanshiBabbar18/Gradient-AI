Put the UCI Student Performance CSV here:

    data/student-por.csv   (Portuguese course, 649 records)   <- default
    data/student-mat.csv   (Mathematics course, 395 records)

Source: https://archive.ics.uci.edu/dataset/320/student+performance
(download the zip, extract it, copy the csv into this folder).
The files are semicolon (;) separated.

If the file is missing, train.py will try to download it automatically.
